# Credit Card Default Analysis Using MySQL

## Project Overview
This project analyzes credit card client data using MySQL to explore customer payment behavior, credit limits, demographic patterns, and default risk.

## Objectives
- Analyze credit card payment defaults.
- Explore customer credit limits and age groups.
- Examine repayment status, billing amounts, and payment amounts.
- Compare default rates across customer segments.
- Practice SQL-based data cleaning, analysis, and reporting.

## Tools & Skills
- MySQL
- MySQL Workbench
- SQL filtering and aggregation
- `CASE` statements and Common Table Expressions (CTEs)
- Window functions and ranking
- Views and stored procedures
- Data validation and segmentation

## Analysis Performed
- Data exploration and validation
- Overall default-rate analysis
- Credit-limit segmentation
- Age and demographic analysis
- Repayment-status analysis
- Billing and payment analysis
- Customer risk segmentation
- SQL reporting using views and stored procedures

## Project File
- `credit_card_clients_organized_fixed.sql` — SQL queries for the project analysis.

## How to Use
1. Open MySQL Workbench and connect to your MySQL server.
2. Import the credit card client dataset into your database.
3. Review the SQL file and confirm the database and table names.
4. Run the queries section by section.
5. Review the result grids to understand the findings.

## Important Notes
- Confirm the dataset column mappings before interpreting the results.
- Risk segments and thresholds are exploratory and should not be treated as a validated credit-risk prediction model.
- Add numerical findings only after verifying the query outputs.

## Conclusion
This project demonstrates the use of SQL for exploring financial customer data, analyzing payment behavior, segmenting customers, and building reusable reports.
